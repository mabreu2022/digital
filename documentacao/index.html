Manual do Software Digital Signage

Guia definitivo para operação, configuração de rede, gerenciamento de mídias, agendamento de campanhas e instalação dos players Android e Desktop.

🌟 1. Visão Geral do Sistema

O Digital Signage Enterprise é uma plataforma robusta de sinalização digital e mídia indoor projetada para operar em regime contínuo (24/7) com arquitetura Offline-First.

⚡

Operação Offline-First

Se a rede cair ou o servidor for reiniciado, os players continuam exibindo a programação em cache sem nenhuma tela preta ou interrupção.

🎯

Direcionamento Inteligente

Mídias e campanhas podem ser veiculadas globalmente para todas as telas ou direcionadas especificamente por IP ou identificador de tela.

🔒

Integridade por MD5

Todos os vídeos e imagens são verificados com hash criptográfico MD5 antes da reprodução, impedindo arquivos corrompidos.

🏛️ 2. Arquitetura do Sistema

O ecossistema é composto por quatro módulos integrados:

Módulo Tecnologia Função Principal
Servidor CMS Lazarus / Free Pascal (LCL + fphttpserver) Painel visual para gestão de mídias, agendamentos, monitor de logs e API REST.
Banco de Dados Firebird 5.0 (SuperServer) Armazenamento relacional de telas, playlists, agendamentos e registros de auditoria (Proof-of-Play).
Player Android Kotlin + Jetpack Compose + ExoPlayer Aplicativo para Smart TVs, TV Boxes e Smartphones com aceleração por hardware.
Player Desktop Lazarus / Free Pascal + LibVLC Player nativo fullscreen para totens e PCs rodando Linux ou Windows.

🖥️ 3. Painel Visual do Servidor (CMS)

O servidor possui uma interface desktop amigável em Lazarus para controle total do sistema:

💡

Como iniciar o Servidor:

No terminal: cd "/home/mauricio/Fontes Lazarus/Digital sign/server" && ./bin/server

Ou no Lazarus IDE: Abra server/Server.lpi e pressione F9.

Recursos do Painel do Servidor:

  • Aba Servidor & Monitor

    Permite iniciar/parar o servidor HTTP na porta desejada (padrão 8080), configurar o endereço do Firebird e acompanhar as requisições dos players em tempo real na caixa de logs.

  • Aba Telas & Players

    Exibe todas as telas que se auto-registraram na rede, mostrando o IP Local, status ONLINE/OFFLINE, versão do app e última telemetria (Heartbeat).

🎬 4. Gerenciamento de Mídias e Playlists

👁️ Pré-visualização Instantânea

Ao clicar em qualquer linha do catálogo de mídias, o painel lateral direito exibe o preview da imagem, dimensões (WxH), tamanho e hash MD5.

▶️ Reprodução no Player do Sistema

Para vídeos e mídias selecionadas, o botão "▶️ Reproduzir / Abrir no Player" abre o arquivo no player padrão do sistema com áudio e controles completos.

📁 Acesso Direto aos Arquivos

O botão "📁 Abrir Pasta de Mídias" abre o explorador de arquivos diretamente no diretório de mídias do servidor.

Como Cadastrar Novas Mídias:

  1. Acesse a aba "Catálogo de Mídias"

    Clique no botão "➕ Adicionar Mídia (Vídeo / Img)".

  2. Selecione o Arquivo

    Formatos suportados: Vídeos (.mp4, .mkv, .avi) e Imagens (.jpg, .png, .webp).

  3. Processamento Automático

    O sistema copia o arquivo para o diretório server/bin/media/, calcula o Hash MD5 e cadastra no banco de dados.

Montagem de Playlists:

Na aba "Playlists", você pode criar grades personalizadas, definir a Playlist Padrão (Fallback) e organizar os itens com botões de Subir ⬆ e Descer ⬇ para reordenar a sequência.

📅 5. Agendamentos e Direcionamento por IP/Tela

O agendador permite criar campanhas com restrições horárias e escolher o público-alvo de cada exibição:

🌐 Direcionamento Global

Selecione "[TODAS AS TELAS - GLOBAL]" para que todas as telas exibam a campanha.

🎯 Direcionamento por Tela / IP

Selecione uma tela específica da lista para veicular conteúdos segmentados (ex: Totem Entrada, TV Refeitório).

⏰ Janela Diária de Horários

Defina horários específicos (ex: das 11:30:00 às 14:00:00 para cardápio de almoço).

📱 6. Player Android (TV Box, Smart TV & Smartphones)

Configuração de IP e Porta no Celular:

  1. Abrir Diálogo de Configuração

    Ao abrir o aplicativo, toque no botão "⚙️ Configurar Servidor" localizado no canto superior da tela ou na mensagem central.

  2. Definir IP e Porta

    Insira o IP da máquina servidora na rede local (ex: 192.168.15.119) e a Porta (ex: 8080).

  3. Testar Conexão

    Toque em "Testar Conexão" para obter feedback visual imediato (Verde = Conexão estabelecida com sucesso).

  4. Salvar e Sincronizar

    Toque em "Salvar e Sincronizar" para baixar os vídeos/imagens e iniciar a reprodução em loop contínuo.

🚀

Inicialização Automática no Boot:

O aplicativo possui o receiver BootCompletedReceiver configurado para abrir automaticamente quando a TV Box ou dispositivo Android for ligado na tomada.

💻 7. Player Desktop (Lazarus / Linux & Windows)

O player desktop roda nativamente em computadores e totens interativos:

# Executar o Player Desktop:
cd "/home/mauricio/Fontes Lazarus/Digital sign/player"

Ele utiliza a biblioteca LibVLC para reprodução acelerada por GPU e suporta Kiosk Mode em tela cheia sem bordas.

🗄️ 8. Banco de Dados Firebird 5.0

Estrutura das tabelas relacionais do sistema:

Tabela Descrição
TELAS Cadastro e telemetria de cada player (UUID, IP, status, versão).
MIDIAS Catálogo de arquivos de vídeo e imagem com MD5 e tamanho.
PLAYLISTS Grades de programação (indicando se é padrão de fallback).
PLAYLIST_ITENS Associação de mídias, ordem de exibição, duração e transições.
AGENDAMENTOS Regras de veiculação por tela/IP, datas, horários e dias da semana.
LOGS_EXIBICAO Auditoria e Proof-of-Play com registro de cada exibição realizada.

📡 9. Referência da API REST

Método Endpoint Descrição
POST /api/v1/players/register Auto-registro e atualização cadastral do player.
GET /api/v1/players/{uuid}/sync Retorna a grade horária ativa, mídias e playlist de fallback.
POST /api/v1/players/{uuid}/heartbeat Ping de telemetria periódico (status, espaço livre, mídia atual).
POST /api/v1/players/{uuid}/proof-of-play Envio em lote do histórico de exibições concluídas.
GET /media/{filename} Download e streaming direto de vídeos e imagens com suporte a cache.

🛠️ 10. Guia de Solução de Problemas (Troubleshooting)

⚠️

O celular/player não conecta no servidor:

1. Verifique se o celular está conectado na mesma rede Wi-Fi/LAN do servidor.

2. Certifique-se de que o firewall do Linux permite a porta 8080: sudo ufw allow 8080/tcp.

3. No app Android, toque em "⚙️ Configurar Servidor", digite o IP correto do computador e clique em "Testar Conexão".

ℹ️

Mídia com erro de reprodução:

Verifique se o arquivo de vídeo é compatível com H.264 / AAC em formato .mp4. O sistema valida automaticamente o Hash MD5 para garantir que o download foi concluído sem corrupção.
